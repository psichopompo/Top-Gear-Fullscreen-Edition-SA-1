# TopGear - Fullscreen Edition — v1.2 (SA-1)

I have modified the single-player mode to display in full-screen, added SA-1 compatibility, and included performance and presentation improvements.

<img width="256" height="224" alt="TopGear - Fullscreen Edition (v1 0) (SA-1) (by Psicopompo)-261115-180410" src="https://github.com/user-attachments/assets/83a2067a-b14d-453d-99a6-26fb3a0b6575" /> <img width="256" height="224" alt="TopGear - Fullscreen Edition (v1 0) (SA-1) (by Psicopompo)-261115-195149" src="https://github.com/user-attachments/assets/070de45c-b920-4951-8417-5467d0ba9c50" />

## What's new in v1.2

- The HUD (race timer, speedometer, gear, laps and position) now updates reliably every frame. Previously it could freeze or lag behind, especially the timer and, during pit stops, the whole HUD.
- Graphics loaded by the game during pit stops are no longer lost.
- The black flicker at the top of the screen during pit stops has been removed.

## What's new in v1.1

- Corrected fuel consumption.
- Fixed graphical corruption in pit stops on the right side of the road.
- Fixed the black screen when starting a race in standalone Snes9x 1.63.

[![TopGear - Fullscreen Edition v1.2 (SA-1)](https://img.youtube.com/vi/7u87DdSbDR0/hqdefault.jpg)](https://youtu.be/7u87DdSbDR0)

## Changes

- Single-player races have been expanded to fill the screen, removing the lower view of the second car in this mode.
- SA-1 support and additional performance optimizations have been incorporated.
- The HUD has been adapted to the expanded view.
- The transition to RESULTS in single-player mode has been corrected.
- Position updates during pit stops have been corrected.
- Sky flashes, lap-message display issues and bridge graphics have been corrected, including objects appearing over bridge walls.

## How to apply the patch

Download the v1.2 ZIP from the **Releases** section.

1. Extract the ZIP archive.
2. Open [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/).
3. Select an unmodified Top Gear (USA) ROM without a copier header: 524,288 bytes, CRC32 `D34C49B7`.
4. Select either the included `.bps` patch or the `.ips` patch. Both produce the same ROM: apply **ONLY ONE**, directly to the original USA ROM.
5. Apply the patch and save the result as:  
   `TopGear - Fullscreen Edition (v1.2) (SA-1) (by Psicopompo).sfc`  
   The patched ROM is 1,048,576 bytes, CRC32 `CDF8FC04`.
6. Open the patched ROM in an SA-1-compatible environment and start from a fresh boot. Save states from earlier versions may retain old code and may not include all fixes.

No previous version of the hack is required. Do not apply the patch to v1.0, v1.1 or another modified ROM. The IPS and BPS patches are alternatives: do not apply both. The package contains both patches and the Spanish and English readme files; no ROM is included.

Tested with Mesen 2.2.1, standalone Snes9x 1.63 and the RetroArch Snes9x core.
